# Privacy rules

- The archive lives in my private Google Drive. It is never published.
- Personal conversations (health, money, relationships, appearance, emotional topics, language practice) are skipped. Mixed chats log only the project parts.
- No passwords or tokens are ever stored. If a platform is logged out, the run logs it and moves on.
- Nothing is posted, sent or published by the workflow.
- This repository holds the method and templates only: no chats, no images, no IDs, no real usage numbers.
